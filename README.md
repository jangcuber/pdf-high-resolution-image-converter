# PDF 고해상도 이미지 변환기 v3

PDF 각 페이지를 고해상도 PNG로 렌더링한 뒤 새 PDF로 다시 만드는 프로그램입니다.

## 새 기능

### 앞부분 N페이지 원본 유지

이제 체크박스 대신 숫자로 지정합니다.

- `0` → 전체 페이지 이미지화
- `1` → 1페이지 원본 유지
- `2` → 1~2페이지 원본 유지

즉, 제출 시스템에서 20단어 이상의 실제 텍스트가 필요하면
1페이지 또는 1~2페이지를 원본으로 남기고 나머지만 이미지화할 수 있습니다.

## 기능

- 150 / 300 / 600 DPI 프리셋
- 72~1200 DPI 직접 입력
- 앞부분 원본 유지 페이지 수 지정
- 페이지 순서 유지
- 원본 페이지 크기 유지
- 진행률 표시
- 작업 취소
- 임시 이미지 자동 삭제
- 페이지별 PNG 보관 옵션

## 설치

Python 3.10 이상 권장

```bash
pip install -r requirements.txt
```

## 실행

```bash
python pdf_rasterizer.py
```

Windows:
- `run_windows.bat`

macOS:
- `run_macos.command`

## 권장 사용 예시

- 제출 시스템이 실제 텍스트 20단어 이상 요구
  - `앞에서 원본 유지할 페이지 수 = 2`
  - 그 뒤의 페이지는 이미지화
